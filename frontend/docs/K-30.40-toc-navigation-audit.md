# K-30.40 — Scroll-Spy TOC Audit

**Branch:** `k30-knowledge-authoring`  
**Scope:** Task E — active heading tracking while scrolling

---

## Implemented

| Capability | Detail |
| ---------- | ------ |
| Scroll spy hook | `useTocScrollSpy` on editor scroll pane |
| Active highlight | `.btoc.active` follows current section |
| Smooth updates | `requestAnimationFrame` on scroll + `ResizeObserver` |
| Manual jump pause | 800ms pause after TOC click to avoid fighting user |
| Toggle headings | Included via existing `extractTOC` / `data-be-heading` indices |

---

## Architecture

```
editorScrollRef (scroll root)
  → measureHeadingPositions(selectors from body)
  → resolveActiveTocIndex(scrollTop, positions)
  → setActiveTocIdx
```

Pure logic in `outlineScrollSpy.ts`; hook in `useTocScrollSpy.ts`.
