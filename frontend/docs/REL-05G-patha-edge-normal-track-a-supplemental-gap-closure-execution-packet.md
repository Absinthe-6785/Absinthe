| Round | Ordered actions (foreground explicit reads) |

a repeat. DIFFERENT requires both own controls succeed, peer fresh reads repeatedly

PASS means determinate `SAME_OBSERVED_STORAGE_SCOPE` or `DIFFERENT_OBSERVED_STORAGE_SCOPE`,
not mandatory sharing. Preserve fixture/integrity violations as FAIL.

## 5. Attempts, STOP and verdict handling

An attempt is immutable once its critical action begins. Preserve all failed, aborted,
mistimed, off-run, timeout, unexpected-restore and duplicate artifacts. Never overwrite
downloads or raw JSON; increased export tails are different artifacts, not edits.
Wrong run/role/build, timer end, missed screenshot, recording failure, accidental reload,
wrong route, unknown ordering or offline-control uncertainty ends the affected control.
Retain evidence, record protocol verdict/reason and new attempt ID if authorized retrying;
new run if stale values/participants/chain threaten contamination. No cleanup/reseed of
a bad attempt to manufacture success. Fixture-data corruption remains FAIL, not erased.

STOP rather than improvise on identity/deployment mismatch, unsafe product/writer impact,
unestablished required UI route/state, unavailable required capture, safe-offline failure,
or excluded capability/privileged/destructive step. Pre-action unattempted rows remain
NOT_EXECUTED with exact reason; attempted evidence gaps remain INCONCLUSIVE. Physical
access absence may be PHYSICAL_ACCESS_REQUIRED, not API absence/impossibility. A concrete
need for excluded capability is PATH_B_REQUIRED / PATH_B_E2_LIKE_CAPABILITY_REQUIRED for
that subpath; return for a new product/platform decision before tooling. Safe unrelated
rows can continue only within the separately authorized execution scope.

Canonical V: PASS is a determinate reviewable bounded measurement with controls; FAIL
is a defined fixture/isolation/integrity violation; INCONCLUSIVE is inadequate evidence.
Record each method sub-result. No default fixture `physicalResult` or UNKNOWN restore
display is final review. Track remains PARTIAL while mandatory observations lack evidence;
even a future complete set of observations cannot qualify other tracks or issue authority.
The historical run's row/track verdicts never change; future review reports its own run.
