## Legacy / Duplicate Surfaces

| Surface | Marker | Issue |
| ------- | ------ | ----- |
| Mobile mini-calendar | `data-planner-legacy-mini-calendar` | Duplicates `CalendarShell` on mobile-only Calendar tab; hardcoded `Mo–Su` weekdays |
| Timeline column | Right column on desktop | Coexists with CalendarShell — intentional dual column |
| Mobile tab bar | 5 tabs (todo/memo/calendar/timeline/…) | Different IA from desktop 3-column layout |

**Recommendation (K-32):** Remove legacy mini-calendar; unify mobile planner chrome.
