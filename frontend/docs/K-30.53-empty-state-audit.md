## Patterns

**Good:** Korean full sentences, context-specific (휴지통이 비어 있습니다)

**Weak:** Single-word **없음** without guidance in primary workflows

**Bad:** English constants in Korean UI (DATABASE_EMPTY_MESSAGE)

---

## Fixes Applied

1. **NoteView empty editor** — Korean copy + **+ 새 노트** button label
2. **ProjectDashboardPanel** — sidebar collection hint for first project
3. **LearningPathOverviewPanel** — «경로 만들기» callout in empty message
4. **ReviewQueuePanel** — positive empty message when queue clear

---

## Recommended (P2)

- Shared empty-state component with optional primary action button
- Localize `DATABASE_EMPTY_MESSAGE` and trace empty formatters
- Pinned/recent workspace cards: add “대시보드 열기” link when empty

---

## Success Criteria

Primary workflow empties (notes, projects, paths, review queue) guide the user toward the next action.
