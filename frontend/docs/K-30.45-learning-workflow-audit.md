# K-30.45 — Learning Workflow Audit

**Branch:** `k30-study-workflows`  
**Scope:** Task G — evaluate learning workflows (audit only)

---

## EJU Preparation

**Strengths:** Study template with topic/summary/mistakes; question blocks for past-paper drills; weak topic flag; exam collections.

**Weaknesses:** No subject-specific templates (日本語, 総合, 数学); no timed practice mode.

**Missing:** Score tracking, mock exam structure, syllabus checklist.

**Future:** EJU template pack, subject tags, practice session timer.

---

## TOEFL Preparation

**Strengths:** Question/answer self-test blocks; reading-style summary sections; review candidates dashboard.

**Weaknesses:** No listening/speaking block types; no section timers.

**Missing:** Integrated task templates, vocabulary SRS.

**Future:** TOEFL section templates, audio question blocks (existing audio block helps).

---

## JLPT Preparation

**Strengths:** Study notes + weak topics map to grammar/vocab review; `#exam-prep` collection.

**Weaknesses:** No JLPT level metadata; no kanji/vocab list blocks.

**Missing:** Level-based filtering (N1–N5), drill decks.

**Future:** JLPT level property, vocabulary table templates.

---

## Language Learning

**Strengths:** Question blocks for recall; connections via wiki links; study dashboard discovery.

**Weaknesses:** No immersion reading pipeline integration with study notes.

**Missing:** SRS, CEFR tracking, dialogue templates.

**Future:** Link study notes to reading notes; manual flashcard blocks.

---

## History Learning

**Strengths:** Timeline-friendly headings; question blocks for causation ("What caused…"); permanent note path from research workflow.

**Weaknesses:** No chronology block or date-indexed views.

**Missing:** Event timeline integration with trace/archive.

**Future:** History study template with chronology section.

---

## Mathematics Learning

**Strengths:** Math blocks (K-30.40); question blocks for problem drills; common mistakes section.

**Weaknesses:** No step-by-step solution block; answer reveal works but not LaTeX-aware in answer block.

**Missing:** Problem numbering, difficulty tags.

**Future:** Worked solution template, math-heavy answer formatting.

---

## Overall

K-30.45 delivers a credible **active learning foundation** without AI or SRS. Next value is exam-specific templates and practice sessions (K-30.46).
