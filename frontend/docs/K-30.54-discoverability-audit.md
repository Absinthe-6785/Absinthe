# K-30.54 — Discoverability Audit

**Branch:** `k30-discoverability-i18n`

---

## Before K-30.54

| Issue | Severity |
| ----- | -------- |
| No global search | Critical |
| Project creation requires property knowledge | Critical |
| Learning path editor hidden | High |
| Empty states without actions | High |
| Collection navigation only via sidebar scroll | Medium |

## Implemented

### Workspace Search (Task A)

- `buildWorkspaceSearch` — notes, folders, tags, collections, projects, milestones, paths, subjects
- `WorkspaceSearchPalette` — grouped results, ranked
- **Ctrl+K** + sidebar button + mobile header button

### Guided Creation (Tasks B/C)

- `CreateProjectDialog` — name, description, subject tag, status → auto properties
- `CreateMilestoneDialog` — name, date, project picker, status → auto link

### Learning Paths (Task D)

- Overview tab shows learning paths section
- Empty state with create CTA (localized)
- Edit path from overview cards

### Deep Links (Task F)

- Project empty → Create Project button
- Study empty → Open Study Collection
- Research empty → Open Research Collection

## Remaining

- Search from Archive/Planner tabs (Notes-only today)
- Recent searches / pinned results
- Breadcrumb back from collection to dashboard

## Success Criteria Met

New users can create projects/milestones and find workspace entities without documentation.
