# K-30.56 — Search Palette Accessibility Audit

**Branch:** `k30-tablet-accessibility-polish`

---

## Improvements

| Feature | Implementation |
| ------- | -------------- |
| Focus trap | `useModalA11y` on palette panel |
| Focus restore | Returns to trigger element on close |
| Escape | Handled by `useModalA11y` (capture phase) |
| Combobox pattern | Input `role="combobox"`, `aria-controls`, `aria-activedescendant` |
| Listbox | Results `role="listbox"`; options `role="option"` + `aria-selected` |
| Filter chips | `role="radiogroup"` + `role="radio"` + `aria-checked` |
| Sections | `role="group"` + `aria-label` per section |
| Keyboard | ArrowUp/Down, Enter (via ref for stale closure fix) |
| Focus visibility | `.abs-focus-ring:focus-visible` on options and filters |
| Tablet layout | Reduced top padding; `maxWidth: min(520px, calc(100vw - 32px))` |

## Success Criteria

**Met:** Workspace search operable without a mouse.
