# K-33.1 — Galaxy System

---

## Visual Components

Each galaxy cluster renders (Universe mode):

| Element | Purpose |
| ------- | ------- |
| Nebula fill | Soft `hsla` radial wash — cluster territory |
| Boundary ring | Dashed circle — cluster edge |
| Centroid marker | Cross + dot at area anchor / brightest star |
| Title label | e.g. `History Galaxy`, zoom-gated at scale |

---

## Assignment (unchanged from K-33)

1. Area note → galaxy anchor
2. Outgoing/backlink to area → member
3. Folder fallback
4. `Uncategorized`

---

## Color System

`galaxyColor(hue, alpha, dark)` — deterministic hue from `galaxyId` hash.

Palette hues: violet, gold, coral, teal, magenta — aligned with Absinthe accent family.

---

## Scale Policy

| Tier | Nodes | Nebula | Labels |
| ---- | ----- | ------ | ------ |
| normal–xlarge | &lt;500 | Always (universe) | zoom ≥ 0.5 |
| massive | 500–999 | zoom ≥ 0.45 | zoom ≥ 0.7 |
| galaxy | 1000+ | zoom ≥ 0.55 | zoom ≥ 0.9 |

## Known Limitations

- Folder galaxies titled generically as `Folder Galaxy`
