# K-30.50 — Dashboard Consolidation Audit

**Branch:** `k30-product-consolidation`  
**Scope:** Task A — UnifiedWorkspaceDashboard

---

## Before (Fragmentation)

| Surface | Location | Issue |
| ------- | -------- | ----- |
| Research Dashboard | Workspace home card | Separate scroll target |
| Study Dashboard | Workspace home card | Duplicated weak-topic visibility |
| Academic Dashboard | Workspace home card | Overlapped with insights |
| Academic Insights | Workspace home card | Overlapped with study/academic |
| Project Dashboard | Workspace home card | No quick actions |
| Subject Maps | Workspace home card | Disconnected from subject workspace |
| Knowledge Clusters | Workspace home card | Buried below maps |
| Knowledge Review | Workspace home card | Separate from insights activity |

Users faced **8+ dashboard cards** on workspace home with overlapping data.

---

## After (Consolidation)

| Section | Content | Source builders |
| ------- | ------- | --------------- |
| **Overview** | Recent activity, insights, review queue | `buildAcademicInsights`, `buildKnowledgeReviewLists` |
| **Learning** | Study, weak topics, subjects, clusters | `buildStudyDashboard`, `buildSubjectDashboard`, `buildKnowledgeClusters` |
| **Research** | Sources, literature, permanent | `buildResearchDashboard` |
| **Projects** | Active projects, milestones, quick actions | `buildProjectDashboard`, `ProjectQuickActions` |

Single **워크스페이스** card with tab navigation replaces fragmented cards.

`buildUnifiedWorkspaceDashboard` composes existing builders — no new scoring logic.
