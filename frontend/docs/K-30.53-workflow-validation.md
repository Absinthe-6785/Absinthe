## Scenario 1 — EJU History

**Goal:** Study Japanese history for EJU exam; track weak topics and subject workspace.

| Step | Path | Friction |
| ---- | ---- | -------- |
| Open subject | Sidebar → 일본사 작업공간 smart collection | OK after terminology fix |
| View progress | Dashboard → 학습 tab → SubjectMapsDashboardPanel | Multiple tabs |
| Review weak areas | exam-weak-topics collection | Secondary collection — collapsed |
| Take notes | Create note in folder | Default title English (New Note) |

**Unnecessary clicks:** Dashboard → 학습 tab → subject card → 작업공간 열기 (3+ clicks from note list)

**Missing shortcuts:** Jump from weak-topic empty to create study note; subject pin from dashboard card

## Scenario 3 — Vocabulary Study

**Goal:** Daily vocabulary review and spaced repetition notes.

| Step | Path | Friction |
| ---- | ---- | -------- |
| Vocabulary workspace | 어휘 작업공간 collection | OK |
| Review notes | exam-review-notes (복습 노트) | 검토 vs 복습 terminology split |
| Create flashcard-style note | Note editor | No SRS — by design |
| Dashboard insight | Study dashboard 복습 후보 | OK |

**Friction:** **복습** vs **검토** may confuse; collections use 복습, maintenance uses 검토 — document distinction.
