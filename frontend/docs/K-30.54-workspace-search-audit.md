# K-30.54 — Workspace Search Audit

**Branch:** `k30-discoverability-i18n`

---

## Architecture

```
NoteView (Ctrl+K, sidebar button, mobile button)
  → WorkspaceSearchPalette
  → buildWorkspaceSearch(query, notes, folders)
  → grouped results → navigation handlers
```

## Search Targets

| Kind | Source | Navigation |
| ---- | ------ | ---------- |
| note | title match | open note |
| project | studyProject containers | open note |
| learning-path | learningPath property slugs | dashboard + path editor |
| collection | SMART_COLLECTIONS names | activate smart collection |
| subject | SUBJECT_DASHBOARDS | activate subject collection |
| tag | note tags | filter by tag |
| milestone | projectMilestone notes | open note |
| folder | folder names | filter by folder |

## Ranking

Priority order: note → project → learning-path → collection/subject → tag → milestone → folder

Within kind: exact match → prefix → contains

## UX

- Desktop: sidebar search button + **Ctrl+K**
- Mobile: search icon in note list header
- Keyboard: ↑↓ navigate, Enter select, Esc close
- Max 8 results per group
