# K-30.40 — Audio Embed Block Audit

**Branch:** `k30-knowledge-authoring`  
**Scope:** Task C — audio embed for language listening notes

---

## Implemented

| Capability | Detail |
| ---------- | ------ |
| Block type | ` ```audio ` fence with URL (+ optional caption line) |
| URL embed | `http(s)://` and `data:audio/` URLs validated |
| Local assets | Same `src` field as images when URL points to hosted asset |
| UI | Compact play/pause control, caption line, URL entry form when empty |
| Serialize | Round-trip through markdown fence format |
