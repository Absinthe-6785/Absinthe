# K-30.40 — Mermaid Block Audit

**Branch:** `k30-knowledge-authoring`  
**Scope:** Task B — lightweight Mermaid diagrams

---

## Implemented

| Capability | Detail |
| ---------- | ------ |
| Block type | ` ```mermaid ` fenced code → `mermaid` block |
| Diagram types | flowchart, graph, sequenceDiagram (Mermaid core) |
| Render | CDN Mermaid with `securityLevel: 'strict'` |
| Source preservation | `block.mermaid` field; edit via textarea overlay |
| Fallback | Monospace source preview when render fails or CDN loading |
| Slash / menu | `/mermaid`; block type menu |

---

## Safety

- SVG injected only from Mermaid library output (strict security level).
- Invalid syntax shows source + error styling — no script execution from user text alone.
- Source always recoverable from markdown export.
