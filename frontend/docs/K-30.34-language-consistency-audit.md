# K-30.34 — Language Consistency Audit

**Context:** Product polish milestone. UI mixes Korean, English, and Japanese on the same screens. This document inventories mixed-language locations and recommends a normalization order. **No i18n implementation in K-30.34.**

**Branch:** `k30-product-polish`

**Method:** String grep across `frontend/src/components/views`, Planner, Archive, and shared store labels; spot-check of user-visible copy in NoteView, BlockEditor, PlannerView, Archive Home.

---

## Executive Summary

| Language | Typical use today | Risk |
| -------- | ----------------- | ---- |
| **Korean** | Block editor placeholders, slash menu labels, Note sidebar chrome, appearance panel | Dominant in Notes edit flow |
| **English** | Mode hints, Archive/Planner section titles, empty states, keyboard shortcuts panel | Dominant in Archive & Planner shells |
| **Japanese** | User-authored note content only (not product chrome) | N/A for product strings |

Primary inconsistency: **Notes tab is Korean-first; Archive and Planner are English-first**, with English hints inside Korean-heavy Note chrome.

## Localization Strategy (recommended, not implemented)

1. **Single product locale per session** — default `ko-KR` for Absinthe primary audience; optional `en-US` later.
2. **String layers:**
   - **Layer A:** Shared chrome (`AppContent` tabs, modals, confirm dialogs)
   - **Layer B:** Feature modules (Notes, Planner, Archive, Health)
   - **Layer C:** Editor block catalog (placeholders, slash, turn-into)
3. **Do not translate user content** — note titles, headings like `1910年 韓国併合` stay as authored.
4. **Avoid inline ternary copy** — consolidate into `messages/ko.ts` + `messages/en.ts` or existing `t()` pipeline.
5. **Reading-mode hints** — match Note sidebar language (KO first).

## Recommended Normalization Order

| Phase | Scope | Effort | Impact |
| ----- | ----- | ------ | ------ |
| **1** | NoteView reading hint + outline empty state + folder form buttons | S | High — visible on every read session |
| **2** | `blockPlaceholders.ts` + slash menu + selection toolbar | M | High — edit flow consistency |
| **3** | NoteView appearance panel + sidebar section labels | M | Medium |
| **4** | Planner CalendarShell mode labels vs legacy Timeline/D-Day | M | Medium — cross-surface |
| **5** | Archive Home section titles + empty states | S | Medium |
| **6** | Full `t()` extraction + locale switcher | L | Future milestone |

**K-30.34 fix applied:** Removed visible `텍스트 입력…` in reading mode (Task A). Hint strings remain mixed until Phase 1.

## Out of Scope (K-30.34)

- Full i18n framework
- Locale switcher in Settings
- Translating user note content or wiki link targets
- Backend/API error message localization
