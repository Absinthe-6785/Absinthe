## Implemented

| Indicator | Meaning |
| --------- | ------- |
| 활동 중 | Active project with activity within 14 days |
| 정체 | Active project with no linked/project activity ≥ 14 days |
| 진행 | Planned or completed status |

Shows milestone completion ratio and days since last activity. No health score.
