# K-30.50 — Smart Collection Audit

**Branch:** `k30-product-consolidation`  
**Scope:** Task B — Primary collection hierarchy

---

## Before

23 smart collections displayed flat within 5 groups. All collections had equal visual weight, making hierarchy unclear.

---

## After

| Primary Category | Primary Collections | Secondary (collapsed) |
| ---------------- | ------------------- | --------------------- |
| **지식 (Knowledge)** | research-sources, map-concepts, recent | literature, permanent, orphan, untagged, backlinks, mentions |
| **학습 (Study)** | exam-study-notes, exam-weak-topics | exam-prep, exam-review-notes |
| **프로젝트 (Projects)** | academic-active-projects, academic-milestones | academic-study-projects, academic-completed-projects |
| **주제 (Subjects)** | All 5 subject workspaces | — |
| **인사이트 (Insights)** | highly-connected | — |

- All **collection IDs preserved** — stored workspace state and links unchanged
- Secondary collections accessible via **더 보기** expand per group
- Auto-expands when a secondary collection is active

- `SmartCollectionGroup.primaryCollectionIds` / `secondaryCollectionIds`
