# K-30.43 — Citation Block Audit

**Branch:** `k30-research-workflows`  
**Scope:** Task B — structured citation blocks inside notes

---

## Implemented

| Field | Storage |
| ----- | ------- |
| Source title | `citationTitle` / fence line 1 |
| Author | `citationAuthor` |
| Year | `citationYear` |
| Page (optional) | `citationPage` / `page:` line |
| URL (optional) | `citationUrl` / `url:` line |

Markdown fence: ` ```citation ` with body `Title | Author | Year`.

Block type registered in editor (`/citation`, slash menu, block menu). Compact read view via `CitationBlock`.

No external lookup or citation database integration.
