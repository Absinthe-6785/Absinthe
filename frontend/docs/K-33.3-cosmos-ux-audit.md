# K-33.3 — Cosmos UX Audit

**Branch:** `k33-3-cosmos-experience`  
**Builds on:** K-33.2 Cosmos Identity & Information Architecture

---

## Scope

Reviewed surfaces: Knowledge Cosmos graph, note editor, properties panel, links panel, workspace dashboard, navigation flows, empty states, and first-time user experience.

---

## Executive Summary

The Cosmos visual identity (K-33.1) and terminology alignment (K-33.2) provide a strong foundation. K-33.3 closes the largest UX gaps through **in-UI onboarding copy**, **localized strings**, and **consistent Cosmos naming** in primary navigation paths.

Remaining friction is concentrated in secondary dashboards, internal code naming (`knowledgeUniverse` module), and the distinction between wiki links, concept relations, and related-note scoring.

## Links Panel

### Panel order (confirmed good)

Concept hub → Concept relations → Learning path → Backlinks → Reference explorer → Related notes → Reading↔source → Bibliography

### Discoverability findings

| Panel | Empty-state guidance | Status |
| ----- | -------------------- | ------ |
| Concept hub | `knCosmosHintConcepts` | Done |
| Related notes | `knCosmosHintRelated` | Done |
| Backlinks | `knCosmosHintBacklinks` | Done |
| Reference explorer | `knCosmosHintReferences` | Done |
| Learning path | Returns null when empty — hint in editor/overview | Partial — see onboarding doc |
| Bibliography | Standard empty copy | Add hint if citation count is zero across note |

### Relationship confusion risk

Users may conflate:

1. **Wiki links** (`[[title]]`) — reference explorer, backlinks
2. **Concept relations** (typed properties) — relations panel
3. **Related notes** (scored similarity) — related notes panel

**Recommendation:** Keep panels separate (current IA is correct). Add cross-links in empty hints pointing to the other mechanism (K-34 micro-copy pass).

## First-Time User Experience

### Current onboarding path

1. User creates note → sees empty properties with Cosmos onboarding
2. User opens graph → empty cosmos explains tiers
3. User opens links panel sections → hints explain each relationship type

### Recommended FTUE sequence (K-34)

1. **Welcome card** on first graph open: 3-line Cosmos hierarchy (Galaxy → Star → Moon)
2. **Progressive disclosure:** after first wiki link, show backlink hint once
3. **Do not** add modal tours — inline hints match Absinthe's calm UX
