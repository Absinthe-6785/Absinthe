# K-30.53 — Terminology Audit

**Branch:** `k30-product-audit`  
**Scope:** Task A — UI language consistency

---

## Standard Adopted

| Concept | Canonical term | Avoid |
| ------- | -------------- | ----- |
| Workspace | **작업공간** | 워크스페이스 (mixed) |
| Review (knowledge) | **검토** | 검토 대기열 for non-queue panels |
| Review (study SRS-like) | **복습** | — |
| Data scope | **전체 노트 기준** | vault 기준 |
| Trash | **휴지통** | Trash |
| New note | **새 노트** | + New Note |

---

## Findings

### English leftovers (high visibility)

| Surface | Examples | Severity |
| ------- | -------- | -------- |
| NoteView shell | Trash, Title, Select a note, Reading mode, Invalid query | High |
| Trace lenses | Milestones, Events, No traces… | Medium |
| Database views | Table/Board, No matching notes | Medium |
| App sidebar | Settings label (fixed), Toggle Dark Mode aria | Low |

### Mixed Korean/English

- Dashboard cards used **워크스페이스** while sidebar used **작업공간**
- Analytics panels showed **vault 기준** in otherwise Korean copy
- **검토 대기열** header above `KnowledgeReviewPanel` (actually “지식 검토” content)
- Sort label **Az 제목** mixes Latin abbreviation with Korean

### Duplicate terminology

| Term | Variants | Resolution |
| ---- | -------- | ---------- |
| Workspace | 작업공간 / 워크스페이스 | Standardize to **작업공간** |
| Review | 검토 / 복습 | Keep both; distinguish context |
| Collection | 스마트 컬렉션 / 컬렉션 | Acceptable — system vs user |
| Empty phrasing | 없음 / 없습니다 / English | Prefer full Korean sentences for primary surfaces |

---

## Fixes Applied (K-30.53)

- NoteView: 휴지통, 제목, 읽기 모드, 잘못된 쿼리, empty editor copy
- Unified dashboard: **지식 검토** section label; **통합 작업공간 대시보드** aria
- Workspace cards: **작업공간**, **주제 작업공간**
- Subject panels: **작업공간 열기**
- Analytics scope: **전체 노트 기준**
- Sidebar: localized Settings label and sign-out tooltip

---

## Remaining (deferred)

- Trace lens section titles (English)
- Database view type labels (Table/Board/Calendar)
- Default note titles on create (Reading Notes, New Project, …)
- Property-key hints in empty states (studyProject)
- Full NoteView toolbar localization (Mark Event, Edit Milestone, …)

---

## Success Criteria

UI uses **작업공간** consistently in dashboard/workspace surfaces; primary NoteView empty states and sidebar chrome are Korean.
