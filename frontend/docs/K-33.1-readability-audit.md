# K-33.1 — Readability Audit

## Scale Tiers

| Tier | Nodes | Label policy |
| ---- | ----- | ------------ |
| normal | &lt;100 | Stars always; planets in focus |
| large | 100–249 | Stars + focus planets |
| xlarge | 250–499 | Focus cluster planets only |
| massive | 500–999 | Stars + focus planets if zoom ≥ 0.85 |
| galaxy | 1000+ | Stars only unless zoom ≥ 1.2 |

---

## Viewport Zoom (`transform.k`)

Labels and nebula scale with zoom:

- Zoom out → suppress ambient planet/moon labels
- Zoom in → reveal galaxy titles and planet labels in focus shell

---

## Focus Universe Depth

| Depth | Meaning | Node opacity (selected active) |
| ----- | ------- | ------------------------------ |
| 0 | Selected note | 100% |
| 1 | Direct neighbors | 94% |
| 2 | Secondary | 72% |
| outside | Unrelated | 6% |

Edges multiply opacity by `focusUniverseEdgeOpacity`.
