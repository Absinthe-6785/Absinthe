# K-30.50 — Project UX Audit

**Branch:** `k30-product-consolidation`  
**Scope:** Task C — ProjectQuickActions

---

## Before

Projects were property-driven (`studyProject`, `projectMilestone`) but discoverable only via:
- Smart collection filters
- Project dashboard card (buried among 8 cards)
- Manual property editing

No one-click project creation from workspace home.

---

## After

`ProjectQuickActions` on unified dashboard **Projects** tab:

| Action | Behavior |
| ------ | -------- |
| **프로젝트 만들기** | Creates note with `studyProject=yes`, status `active` |
| **마일스톤 만들기** | Creates note with `projectMilestone=yes`, links to active project or first active project |
| **프로젝트 노트 열기** | Activates `academic-active-projects` smart collection |

No modal redesign. No schema changes.
