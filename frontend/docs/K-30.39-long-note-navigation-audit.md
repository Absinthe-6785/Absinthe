## Implemented Improvements (K-30.39)

1. **TOC header count** — `목차 (N)` when headings exist  
2. **Toggle heading marker** — `H2▼` in TOC rows for `#>` headings  
3. **Empty-state hint** — `# · #> 토글 제목 · /toggle1`  
4. **Korean aria-labels** — 섹션 펼치기 / 접기  
5. **`TocItem.isToggleHeading`** — metadata for panel styling
