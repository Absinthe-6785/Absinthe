## Remaining Korean Hardcoded Strings (user-visible)

### P0 — Note workspace (`NoteView.tsx`)

Large legacy inline-KO region (~40 strings): sidebar chrome (`노트`, `추가`, `취소`, `대시보드`), editor toolbar, settings panel, TOC panel header (`목차`), empty TOC copy, graph link label (`그래프 보기`), image drop hint.

**Impact:** English/Japanese users see mixed-language Note tab even when Archive/Planner are fully localized.

### P1 — Graph toolbar (`NoteGraphView.tsx`)

| String | Location |
| ------ | -------- |
| `노드 검색…` | Search placeholder |
| `고립 {n}` / toggle titles | Isolated node filter |
| `제목 없음` | Node `<title>` fallback |
| `폴더 N` | Folder legend fallback |
| `scroll=줌 · drag=팬 · hover=제목` | Status bar |
| Search no-results message | Bottom overlay |

Keys exist for some graph strings (`graphHoverHint`, `graphHoverConnected`) but are not wired in `NoteGraphView`.

### P1 — Knowledge panels

| File | Examples |
| ---- | -------- |
| `NoteRelationsPanel.tsx` | `대상 없음`, `출처 없음` |
| `ConceptRelationsPanel.tsx` | `대상 없음` |
| `LocalGraphView.tsx` | `미리보기:` prefix |
| `reviewQueue.ts` | `연결 N개`, `마일스톤 노트` |

### P2 — Projection-only (English browse labels OK when `locale: en-US`)

`buildArchiveBrowseLinks` uses `resolveArchiveBrowseStaticLabels(locale)` — verified in tests with `options: { locale: 'en-US' }`. Browse **link** text follows locale; section **titles** follow UI `t()`.

### P2 — Comments only

Korean in `//` comments across Planner/Health/Graph — not user-visible.
