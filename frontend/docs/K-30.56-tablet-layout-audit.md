# K-30.56 — Tablet Layout Audit

**Branch:** `k30-tablet-accessibility-polish`

---

## Breakpoints

| Tier | Width | Hook |
| ---- | ----- | ---- |
| Mobile | `<768px` | `isMobile` |
| Tablet | `768–1023px` | `isTablet` |
| Desktop | `≥1024px` | default |

## Changes

| Surface | Issue | Fix |
| ------- | ----- | --- |
| **NoteView** | Tablet treated as desktop — cramped 3-column | `isCompactChrome`; auto-collapse sidebar; narrower list (168px); workspace panel 38%; search button in list header |
| **NoteView** | Right panel fixed 210px | Drawer on compact chrome; 190px on tablet desktop |
| **WorkspaceDashboardView** | Tablet padding same as desktop | `dashboardOuterPadding(isMobile, isTablet)` → 10px |
| **Subject/Project/Milestone panels** | Touch targets mobile-only | `touchMinSize(isMobile, isTablet)` → 44px |
| **Planner week** | 7-day stack until 1024px | `md:grid-cols-2` two-column week at tablet |

## Remaining

- NoteView workspace mode still tight below 900px with right panel open
- Unified dashboard vertical card stack (K-30.52 P3)

## Success Criteria

**Met:** Low-risk tablet layout improvements at 768–1024px without redesign.
