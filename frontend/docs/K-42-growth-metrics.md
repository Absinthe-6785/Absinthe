# K-42 Growth Metrics

## Vault Growth (current period)

| Metric | Source |
|--------|--------|
| Notes Created | `createdAt` in period window |
| Links Created | Snapshot link count delta |
| Areas Created | Area notes created in period |

## Structural Growth (current state)

| Metric | Source |
|--------|--------|
| Hub Count | Area notes + core/major classification |
| Galaxy Count | Unique galaxy IDs |
| Connection Density | links ÷ notes |

## Discovery Growth

| Metric | Source |
|--------|--------|
| Discoveries Generated | Open discovery feed count |
| Discoveries Resolved | Heuristic sum from discovery history |
| Connections Added | Period link delta |
