# K-30.42 — Stale Notes Audit

**Branch:** `k30-review-workflows`  
**Scope:** Task A — neglected note detection

---

## Implemented

| Capability | Detail |
| ---------- | ------ |
| Metadata | `lastOpenedAt` on `NoteBase`; recorded in `setActiveNoteId` |
| Staleness rule | Both open AND edit older than threshold |
| Tiers | 30+, 60+, 90+ day exclusive buckets |
| UI | `StaleNotesPanel` on workspace dashboard **지식 유지보수** |
| Utility | `buildStaleNotesBuckets`, `isStaleNote`, `staleTierForNote` |

Legacy notes without `lastOpenedAt` fall back to `updatedAt` for open activity.

---

## Success Criteria

| Criterion | Status |
| --------- | ------ |
| Detect not opened recently | Met (`lastOpenedAt`) |
| Detect not edited recently | Met (`updatedAt`) |
| 30 / 60 / 90 day sections | Met |

---

## Remaining Friction

| Issue | Priority | Notes |
| ----- | -------- | ----- |
| Reading mode open not tracked separately | P3 | Same as editor open today |
| Empty-title notes excluded | By design | — |
| No snooze/dismiss | P3 | Manual review only |
