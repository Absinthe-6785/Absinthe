# K-30.44 — Reading ↔ Source Link Audit

**Branch:** `k30-citation-workspaces`  
**Scope:** Task D — explicit reading note ↔ source note linkage

---

## Implemented

| Relation | Direction |
| -------- | --------- |
| `source` | Reading note → source note ID |
| `readingNotes` | Source note → reading note IDs |

`ReadingSourceLinkPanel` in Links tab: link picker, navigate, unlink. Creating a reading note while viewing a source note auto-links both directions.

---

## Success Criteria

| Criterion | Status |
| --------- | ------ |
| Explicit linkage | Met |
| Bidirectional navigation | Met |

---

## Remaining Friction

| Issue | Priority | Notes |
| ----- | -------- | ----- |
| One source per reading note | P3 | Single `source` relation |
| Source picker limited to `noteKind: source` | P2 | By design |
| No graph edge styling for link type | P3 | Uses relation layer |

---

## Recommended Follow-up (K-30.45)

Multiple sources per reading note, source map view, auto-suggest source from title.
