## Node Overlap

- **Small (< 50 nodes):** Labels on hover/active/search — acceptable
- **Medium (50–100):** `shouldShowGraphNodeLabel` reduces ambient labels; hubs on hover
- **Large (100+):** Labels mostly hidden except hover/search; overlap reduced but dense clusters remain

**Ceiling:** No clustering/WebGL; 500+ nodes will overlap and slow simulation (documented in K-31 graph scale audit).

---

## Label Readability

| Tier | Behavior |
| ---- | -------- |
| Active / hovered / search match | Label shown |
| High-degree hubs | May show abbreviated label per scale policy |
| Default | No ambient label (K-31 quick win) |

**Issue:** Toolbar and status strings still Korean when `language: en` (see localization audit).

---

## Scaling Beyond 100 Nodes

`graphRepulsionStrength(nodeCount)` and `graphSimulationAlphaFloor(nodeCount)` tune forces.  
No spatial indexing or level-of-detail beyond label suppression.

---

## Clustering Quality

No semantic clustering — layout is force-directed only. Folder colors provide weak grouping.

---

## Usability for Real Knowledge Graphs

| Strength | Weakness |
| -------- | -------- |
| Search + isolate filter help navigation | No cluster collapse |
| Pan/zoom works | Performance degrades at 500+ |
| Click to open note | Mixed-language toolbar |
| Scale-aware label policy | Untitled nodes show KO fallback in SVG `<title>` |
