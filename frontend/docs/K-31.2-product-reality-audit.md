## Task A — Language System Audit (P0)

### Root cause

Archive Home components imported `getTranslator` but rendered **hardcoded Korean literals** in JSX. Planner sub-surfaces (`CalendarModeSwitcher`, `WeeklyTimetableSection`, D-Day / Timeline headers in `PlannerView`) bypassed i18n entirely.

### Gap list (verified → fixed)

| Surface | Issue | Files |
| ------- | ----- | ----- |
| Archive Home frame | Title/subtitle from projection (KO default) instead of app language | `ArchiveHomeView.tsx` |
| Archive empty hint | Hardcoded KO | `ArchiveHomeView.tsx` |
| Mark calendar | Section title, empty state, density legend | `ArchiveMarkCalendar.tsx` |
| Recent milestones | Section title, empty state | `ArchiveRecentMilestones.tsx` |
| Area pills | Section title, empty state | `ArchiveAreaPills.tsx` |
| Browse links | Section title, empty state | `ArchiveBrowseLinks.tsx`, `ArchiveBranchView.tsx` |
| Calendar mode tabs | Hardcoded `월/주/일/아젠다` | `CalendarModeSwitcher.tsx` |
| Weekly timetable | Weekdays, modal, toasts, confirm, add/save | `WeeklyTimetableSection.tsx` |
| Planner D-Day / Memo / Timeline | Hardcoded KO headers and placeholders | `PlannerView.tsx` |
| Timeline carry-over badges | Mixed EN/KO | `PlannerView.tsx` |

### Keys added (`frontend/src/lib/i18n.ts`)

`archiveHomeTitle`, `archiveHomeSubtitle`, `archiveHomeEmptyHint`, `archiveMarkCalendarTitle`, `archiveMarkCalendarNoMarks`, `archiveMarkDensityLow/High`, `archiveRecentMilestonesTitle/Empty`, `archiveAreaTitle/Empty`, `archiveBrowseTitle/Empty`, `plannerCalendarModeMonth/Week/Day/Agenda`, `plannerWeekly*`, `weekdayMon`–`weekdaySun`, `ddayTitlePlaceholder`, `plannerFromYesterday`, `plannerUntilTomorrow`.

### Remaining localization debt (not fixed — out of scope)

| Surface | Notes |
| ------- | ----- |
| `NoteView.tsx` | Large legacy inline KO strings (sidebar, TOC, settings panel) |
| `NoteGraphView.tsx` | Graph toolbar counters |
| Archive browse **link labels** from projection | `buildArchiveBrowseLinks` locale-aware; UI section titles now i18n |
| Database weekday headers | English abbreviations in legacy mobile mini-calendar |

## Task E — Planner Reality Audit (P1)

### Verified working

- Day / Week / Month / Agenda views via `CalendarShell` + `CalendarModeSwitcher`
- Weekly Timetable (expand/collapse, CRUD modal)
- Timeline (day schedules, carry-over badges)
- D-Day list + modal
- Routine + Todo columns with i18n labels

### Cleanup recommendations (no code changes this pass)

1. **Remove legacy mobile mini-calendar** (`data-planner-legacy-mini-calendar`) — duplicates CalendarShell on desktop; English weekday headers hardcoded as `Mo–Su`.
2. **Unify mobile planner tabs** — five tabs (todo, memo, calendar, timeline) vs desktop three-column layout creates duplicate navigation paths.
3. **Archive browse projection labels** — ensure `useArchiveHomeProjection` passes user locale so link text matches section language.
4. **Weekly timetable default collapsed** — discoverability trade-off; consider persisting expand state.

### Dead-end interactions

None found in audited flows; exception-day modal and schedule modals complete with save/cancel.
