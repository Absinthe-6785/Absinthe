## F-5G — Restore as paragraph

**Problem:** `UnsupportedBlock` is read-only fallback; user cannot recover content in-place.

**UX:**
- Button: **Restore as paragraph**
- Action: `onRecover(blockId)` → `convertBlock(id, 'paragraph')` with `content` = plain text from `block.content` or table fallback string
- Wired from `SafeBlockRenderer` / `BlockEditorInner` via `handleBlockChange`

**Scope:** ~40 lines in `UnsupportedBlock.tsx` + one callback in `BlockEditor.tsx`

---

## F-5F — Diagnostics (dev + optional settings flag)

**Panel fields (per block on hover or sidebar):**
- `block.id`, `block.type` (raw + sanitized)
- Last boundary error message (from `SafeBlockRenderer` ref or context)
- `validateDocument` repair flags (new field on repair: `repaired: string[]`)

**Implementation sketch:**
- `EditorDiagnosticsCtx` at `BlockEditorInner` root
- `registerBlockDiagnostic(id, info)` called from boundary `componentDidCatch`
- Toggle: `localStorage.absinthe_editor_diagnostics` or dev-only `import.meta.env.DEV`

**Non-goals:** Full React DevTools replacement; production telemetry.

---

## F-5C — Paste normalization (minimal)

**Frozen:** `pasteStructure.ts`, `blockPaste.ts` — extend only via new entry points.

**Targets:**
1. Gemini HTML tables with `colgroup` / extra wrapper `<div>`
2. Pipe tables with empty header row
3. TSV with BOM prefix (`\ufeff`)

**Approach:**
- New `pasteNormalize.ts` (pure functions) called from `prepareStructuredPasteText` **wrapper** in `blockPaste.ts` (single call site, no logic fork inside frozen file if possible — or one-line pre-hook exported from new module)

---

## F-5D — AI paste parser (P2)

**Input:** clipboard `text/html` + `text/plain` from Gemini/ChatGPT  
**Output:** `Block[]` before `validateDocument`

**Pipeline:**
```
detectAiPaste(html) → aiPasteParser.parse(html) → validateDocument(blocks)
```

**Detection heuristics:**
- HTML contains `<table` + Gemini/ChatGPT wrapper classes or `data-` attributes
- Plain text starts with markdown pipe block

**Not in F-5.1** — design only; implement after F-5G + F-5F + editor-next stable.
