## Features Added

### Recent items
- `workspaceSearchRecent.ts` — localStorage, max 8 entries
- Shown when query is empty (before suggestions)
- Recorded on palette selection

### Empty-query suggestions
- `buildWorkspaceSearchSuggestions()` — recent notes, active projects, learning paths, key collections, subjects
- Grouped like search results

### Ranking rules

Documented in `WORKSPACE_SEARCH_RANKING_DOC` (`buildWorkspaceSearch.ts`):

1. **Match quality:** exact title (0) → prefix (1) → contains (2)
2. **Kind priority:** note → project → learning-path → collection/subject → tag → milestone → folder
3. **Exact-title boost:** additional score reduction within kind
