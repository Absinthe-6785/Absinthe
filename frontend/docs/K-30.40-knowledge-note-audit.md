## 1. EJU history workflow

**Strengths:** Heading hierarchy for eras/topics; toggle headings for expandable timelines; callouts for exam tips; footnotes for textbook page refs (new); Mermaid for cause-effect flowcharts (new).

**Weaknesses:** No native date/event template; footnote ids manual; long chronology tables still manual.

**Missing tools:** Timeline block, citation export, date-stamped heading snippet.

**Next priorities:** P1 footnote renumber; P2 timeline/Mermaid templates in slash menu; P3 event-date properties (not planner).

**Weaknesses:** No furigana/ruby; no cloze; audio upload not drag-drop.

**Weaknesses:** No question-type templates; no timer integration; dual-column reading layout missing.

**Missing tools:** Columns block, passage + question paired layout, word-count stats.

**Next priorities:** P1 columns block (roadmap P1); P2 TOEFL slash snippets; P3 practice timer (outside planner).

**Next priorities:** P1 advanced math (align, cases); P2 equation numbers; P3 graphing (outside scope today).
