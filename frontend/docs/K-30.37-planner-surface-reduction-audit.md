## What CalendarShell Already Replaces

- Month/week/day/agenda browsing and period navigation
- Note-backed event read surfaces
- Day schedule list + CRUD (K-30.31)
- Weekly template **hints** (read-only in Week/Day)
- Legacy D-Day **countdowns** (read-only in Month/Agenda)
- Routine/todo **summaries** (read-only)

---

## What Remains Unique

| Surface | Unique capability |
| ------- | ----------------- |
| Timeline | Time-proportional 48-slot grid, auto-scroll, carry-over layout |
| Routines Col-1 | Checkbox CRUD, exception day modal |
| Todos Col-1 | Add/toggle/edit/delete for selected day |
| Weekly Timetable | Recurring template CRUD |
| D-Day panel | Legacy D-Day API CRUD |
| Memo | Planner-local folder sidebar + inline editor |
| Legacy mini calendar (mobile) | `markedDates` domain dots |
| Schedule modal | Overlap confirm, `end_next_day`, color — shared by Timeline + Day |

---

## Safe Removals (Demotion Only)

| Candidate | Action | Risk |
| --------- | ------ | ---- |
| Legacy mini calendar desktop | **Done K-30.32** — hidden `lg+` | Low |
| Mobile `calendar` tab | Retire when marks migrate to Shell Month | Medium |
| Memo column | Collapse / link to Note tab | Medium |
| Timeline display | Hide when Day grid parity | High — grid UX gap |
| D-Day CRUD panel | Read-only strip → Note events | High — needs Event CRUD |

**Do not remove:** Weekly Timetable, routine/todo CRUD, schedule modal, shared handlers.

---

## Unsafe Removals

- Timeline CRUD before Day View grid parity
- Weekly Timetable before Shell owns template CRUD
- D-Day panel before Event architecture CRUD
- Memo without Note-tab parity banner

---

## Recommended K-30.38 Migration Plan

1. **Planner tab simplification** — Retire mobile `calendar` tab; document mark-dot migration to Month projection.
2. **Memo demotion** — Deprecation banner; default event clicks to Note tab only.
3. **Timeline demotion** — Hide Timeline on `lg+` when Day View gains optional grid mode (parity spike first).
4. **D-Day read-only phase** — Panel shows countdowns only; CRUD via Note events + Agenda.
5. **Language Phase 3** — Remaining Col-1 headers and mobile tab chrome via `t()`.

**Explicitly out of scope for K-30.38:** Toggle Heading, callouts, protein tracker, archive/graph redesign.
