## Comparison — Obsidian

| Obsidian | Absinthe | Gap |
| -------- | -------- | --- |
| Markdown-first | Block model + markdown export | Stronger WYSIWYG, same storage story |
| Folding headings | Toggle headings | Similar UX, different syntax (`#>`) |
| Callouts (`> [!note]`) | Emoji callouts | No Obsidian admonition syntax alias |
| `$...$` / `$$...$$` | Math block | Comparable |
| Dataview / queries | Tags + graph | No query language |
| Excalidraw / canvas | — | Future embed class |

## Absinthe-Specific Opportunities

1. **Toggle headings + outline + graph** — hierarchical study modules without leaving the block model.
2. **Korean-first slash labels** — callout presets match local study-note vocabulary (정보·팁·주의·요약·질문).
3. **Wiki + tags in same inline toolbar** — knowledge graph stays first-class vs Notion mentions.
4. **Planner / archive separation** — block work stays in notes; avoid Notion-style scope creep.
5. **Semantic clipboard** — toggles and headings round-trip; extend to callout/math paste polish.
