## 5. Desktop layout hierarchy

Target order:

```text
CalendarShell (Day default)
    ↓
Timeline
    ↓
D-Day → Routines → Tasks
    ↓
Memo
```

### Before (K-32)

```text
[CalendarShell]
[Routines | Tasks] [D-Day | Memo] [Timeline]
```

### After (K-32.1)

```text
[CalendarShell — Day mode default]
[Timeline] [D-Day → Routines → Tasks] [Memo]
     ↑ lg:order-1      ↑ lg:order-2         ↑ lg:order-3
```

DOM columns use `lg:order-*` so Timeline renders first without breaking mobile tab wiring.

Markers: `data-planner-column="timeline|planning|memo"`
