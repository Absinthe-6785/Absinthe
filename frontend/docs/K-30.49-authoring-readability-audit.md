# K-30.49 — Authoring Readability Audit

**Branch:** `k30-editor-workspace-stabilization`  
**Scope:** Task G — authoring ergonomics (audit only)

---

## Evaluated

| Area | Strengths | Weaknesses |
| ---- | --------- | ---------- |
| Math readability | Symbol shortcuts added; unicode preserved in round-trip | No dedicated math block preview |
| List hierarchy | Tab indent/outdent works | Deep nesting hard to scan in long notes |
| Long-note scanning | TOC in sidebar, headings | Heading density user-dependent |
| Study-note ergonomics | Question/answer blocks, weak-topic flag | Template length intimidating |

No editor architecture redesign per scope.

---

## Recommendations

1. **P1** — Collapsible section headers in study template
2. **P2** — Heading outline mini-map in editor gutter
3. **P3** — List depth visual guides

---

## Exclusions honored

No editor architecture redesign.
