# K-30.38 — Note Authoring Audit

**Branch:** `k30-advanced-blocks`  
**Scope:** Task G — audit only

---

## 1. Long-form study notes

**Works well:** Headings, toggle headings (new), callouts for key points, code blocks, nested toggles for chapters.

**Friction:**

- No in-document TOC block for print/export layouts
- Selection toolbar lacks strike/highlight for emphasis density
- Very long notes: virtual list helps; cross-chapter drag still heavy

**Recommended milestones:** K-30.39 strike/highlight toolbar; K-30.41 in-doc TOC block.

---

## 2. Language learning notes

**Works well:** Callouts for grammar tips (팁/주의), toggles for vocabulary lists, wiki links between lesson notes.

**Friction:**

- No ruby/furigana or IPA inline helpers
- No cloze / flashcard block (Obsidian plugins territory)
- Audio pronunciation embed missing

**Recommended milestones:** K-30.40 embed block (audio); K-30.42 optional cloze syntax (if prioritized).

---

## 3. Timeline / history notes

**Works well:** Heading hierarchy, numbered lists, callout “요약”, graph for concept links.

**Friction:**

- No native timeline / date heading templates
- Mermaid or table-based timelines are manual
- Planner is separate from note body (by design)

**Recommended milestones:** K-30.40 Mermaid block; K-30.39 date-stamped heading snippet in slash menu.

---

## 4. Mathematical notes

**Works well:** Math block with KaTeX, `$$` round-trip, slash `/math`.

**Friction:**

- No live preview while typing in split pane
- Inline `$...$` on its own line works; mixed inline-in-paragraph is limited
- No common LaTeX snippet palette

**Recommended milestones:** K-30.39 math toolbar snippets; K-30.40 equation numbering (optional).

---

## 5. Research notes

**Works well:** Wiki links, tags, callout “질문”, outline navigation, archive workspace.

**Friction:**

- No footnotes / citation block
- No PDF embed or highlight import
- URL links not in selection toolbar (wiki-centric)

**Recommended milestones:** K-30.40 footnote block; K-30.41 PDF embed read-only.
