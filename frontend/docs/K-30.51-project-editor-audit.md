## Implemented

| Field | Mechanism |
| ----- | --------- |

| Description | `studyProjectDescription` via textarea |

| Linked notes | `buildProjectEditorData` + navigable list |
| Milestones | `filterProjectMilestones` + navigable list |

Shown in **Properties** sidebar when viewing a project container note (`studyProject=yes`).

`buildProjectEditorData` composes existing models — no schema changes.
