# K-38 Discovery Feed

The **Discover** tab (Compass icon) in the Knowledge Context panel.

## Sections (ranked by score within each)

1. Forgotten Knowledge
2. Missing Connections
3. Emerging Topics
4. Weak Hubs
5. Knowledge Drift

Default limits: 6 items per section, 30 total in global ranked list.

## Actions

| Section | Actions |
|---------|---------|
| Forgotten / Drift | Revisit → navigate to note |
| Missing connection | Open, Create relation |
| Emerging topic | Open first cluster note |
| Weak hub | Create hub (K-37 template) |

## Entry points

- Knowledge Context **Discover** tab
- Dashboard **Today's discoveries** card → Open Discover
- Graph HUD **Open Discover** / **Review**
- Search result badge: *Suggested by Discovery Engine*

## Empty state

"No discoveries right now" when all signal collectors return empty.
