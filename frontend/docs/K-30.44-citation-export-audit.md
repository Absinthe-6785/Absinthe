# K-30.44 — Citation Export Audit

**Branch:** `k30-citation-workspaces`  
**Scope:** Task A — APA and BibTeX export (export only)

---

## Implemented

| Format | Module | Entry point |
| ------ | ------ | ----------- |
| APA | `citationExport.ts` → `formatCitationAPA` | Bibliography panel **APA** button |
| BibTeX | `citationExport.ts` → `formatCitationBibTeX` | Bibliography panel **BibTeX** button |

Note-local export copies all citation blocks in the active note to clipboard. Vault rollup helper `collectAllCitationsFromNotes` available for future use.

No import. No external citation databases.
