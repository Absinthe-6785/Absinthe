# K-30.55 — Search Filter Audit

**Branch:** `k30-localization-search-polish`

---

## Filters

| Chip | `WorkspaceSearchFilter` | Kinds included |
| ---- | ----------------------- | -------------- |
| All | `all` | everything |
| Notes | `note` | notes, folders, tags |
| Projects | `project` | projects, milestones |
| Paths | `learning-path` | learning paths only |
| Collections | `collection` | collections, tags, folders |
| Subjects | `subject` | subject dashboards |

## UX

- Horizontal chip row in `WorkspaceSearchPalette`
- Filters apply to search results, suggestions, and recent groups
- No query language — plain text + kind filter only
- Labels: `searchFilter*` keys (en/ko/ja)

## Implementation

- `KINDS_BY_FILTER` map in `buildWorkspaceSearch.ts`
- Palette state: `filter` passed to `buildWorkspaceSearch`, `buildWorkspaceSearchSuggestions`, `buildWorkspaceSearchRecentGroups`

## Success Criteria

**Met:** Lightweight filters without advanced query syntax.
