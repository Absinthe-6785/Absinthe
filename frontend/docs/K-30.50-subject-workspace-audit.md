# K-30.50 — Subject Workspace Audit

**Branch:** `k30-product-consolidation`  
**Scope:** Task E — SubjectWorkspacePanel

---

## Before

Five subjects (Japanese History, Politics, Economics, TOEFL, Vocabulary) had:
- Tag-based smart collections
- Compact entries in Subject Maps dashboard card
- No unified per-subject view combining projects, weak topics, study notes, concepts, activity

---

## After

`SubjectWorkspacePanel` + `SubjectWorkspacesPanel` (tabbed) on workspace home:

| Section | Data source |
| ------- | ----------- |
| Projects | `filterStudyProjectContainers` + subject tag |
| Weak topics | `filterWeakTopicNotes` + subject tag |
| Study notes | `isStudyNote` + subject tag |
| Concepts | `isConceptNote` + subject tag |
| Activity | Recent tagged notes with kind labels |
| Summary stats | note/concept/project/weak counts |

**워크스페이스 열기** activates subject smart collection.

Also integrated into unified dashboard **Learning** tab via `SubjectMapsDashboardPanel`.
