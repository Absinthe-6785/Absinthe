## Heading Controls

- H1–H4 buttons convert the **entire block**, not the selected span.
- Active state reflects block type only for plain `heading1`–`heading4`; **toggle headings are not detected** (`deriveToolbarFormats`).
- No “paragraph로 되돌리기” button when a heading is active.
- Toggle header edits share the toolbar but heading buttons produce plain headings, which can unintentionally flatten toggle structure.

## Discoverability

| Strength | Weakness |
| -------- | ---------- |
| Korean labels + shortcut hints on hover | No first-run hint; toolbar is invisible until selection |
| Grouped sections (서식 / 제목 / 링크 / 태그) | Narrow blocks and mobile: toolbar can clip off-screen |
| Consistent with markdown storage | Power users must know markdown delimiters for strike/highlight |
