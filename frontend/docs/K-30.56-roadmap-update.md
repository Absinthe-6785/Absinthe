## Completed (K-30.56)

- Tablet layout tier for NoteView (768–1023px)
- `useModalA11y` focus trap + restore across dialogs
- Workspace search keyboard/a11y (listbox, radiogroup, focus ring)

- Planner week two-column tablet grid

## Future Opportunities

- Reduced-motion preferences
- High-contrast theme variant

## Recommended K-30.57 — Block Editor Accessibility & Motion

- Localize and keyboard-navigate slash command palette

Rationale: App chrome is now accessible; remaining friction is in the editing surface where users spend most time.
