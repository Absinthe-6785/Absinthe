# K-30.40 — Footnote Block Audit

**Branch:** `k30-knowledge-authoring`  
**Scope:** Task A — footnote block system

---

## Implemented

| Capability | Detail |
| ---------- | ------ |
| Parse | `[^id]: text` → `footnote` block; inline `[^id]` preserved in paragraph content |
| Serialize | Definition blocks and inline refs round-trip via `blocksToMarkdown` |
| Render | `FootnoteBlock` for definitions; `FootnoteReferenceSection` in reading mode |
| Navigation | Click `[^id]` superscript scrolls to `#fn-{id}` anchor |
| Slash / menu | `/footnote`, `/fn`; block type menu entry |
| Copy/paste | Fenced-style definition lines and inline refs survive markdown paste |

---

## Syntax

```markdown
EJU historians cite multiple sources[^1] in one paragraph.

[^1]: 教科書 p.42 — primary timeline reference.
[^note]: Named ids supported alongside numeric ids.
```

---

## Success Criteria

| Criterion | Status |
| --------- | ------ |
| Academic-style inline references | Met |
| Reference section at document end (reading) | Met |
| Copy/paste from Obsidian-style markdown | Met |

---

## Remaining Friction

| Issue | Priority | Notes |
| ----- | -------- | ----- |
| No auto-renumber on delete/reorder | P2 | Manual id management |
| Reference section not shown in edit mode | P3 | Definitions visible as blocks |
| No back-link from definition to first cite | P3 | Click-to-return |
| Export/print footnote formatting | P2 | PDF pipeline later |
