# K-30.41 — Knowledge Workflow Audit

**Branch:** `k30-knowledge-workflows`  
**Scope:** Task F — workflow evaluation (audit only)

---

## 1. Capture

**Strengths:** Quick capture on workspace dashboard, slash blocks, inbox tag, task/journal templates.

**Weaknesses:** No capture from browser clipper; audio/footnote capture manual.

**Missing:** Web clipper, voice memo pipeline.

**Next priorities:** P2 audio file drop; P3 capture templates per subject.

---

## 2. Organize

**Strengths:** Folders, tags, properties, database views, smart collections.

**Weaknesses:** Organization spread across sidebar + properties + tags panels.

**Missing:** Unified metadata editor; bulk tag apply.

**Next priorities:** P2 metadata quick-edit; P3 bulk operations.

---

## 3. Connect

**Strengths:** Wiki links, relations panel, local graph, K-30.41 backlink + reference explorer.

**Weaknesses:** Relation authoring still property-heavy; broken link cleanup manual.

**Missing:** Link health report vault-wide.

**Next priorities:** P1 broken link dashboard; P2 relation shortcuts in editor.

---

## 4. Discover

**Strengths:** Related notes, graph expand, search + query syntax, review lists.

**Weaknesses:** Discover surfaces split across dashboard vs right panel.

**Missing:** Global "similar to this note" from editor toolbar.

**Next priorities:** P2 mobile discovery drawer; P3 saved discovery views.

---

## 5. Review

**Strengths:** K-30.41 review dashboard (recent, linked, stale); archive trace for history notes.

**Weaknesses:** No visit history; "least revisited" is updatedAt proxy.

**Missing:** Explicit review queue; flashcards (deferred).

**Next priorities:** P1 last-opened metadata; P2 review queue pins.

---

## 6. Archive

**Strengths:** Archive home, trace lenses, area discovery — unchanged by K-30.41 (per charter).

**Weaknesses:** Archive separate mental model from daily notes review.

**Missing:** Bridge from review dashboard to archive periods.

**Next priorities:** P3 "notes from this period" shortcut in review card.

---

## Post K-30.41 summary

Workflow shift: from **authoring blocks** (K-30.38–40) to **relationship navigation** without planner/archive/graph redesign.
