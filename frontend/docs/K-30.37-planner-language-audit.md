# K-30.37 — Planner Legacy Language Audit

**Branch:** `k30-workspace-consistency`  
**Scope:** Task D — Timeline, D-Day, Weekly Timetable, Memo, schedule dialogs

---

## Summary

CalendarShell and mobile tabs were partially Korean via `t()`. Legacy columns below the shell still had English section headers and Weekly Timetable CRUD copy. K-30.37 normalizes **visible legacy labels** without removing surfaces.

---

## Wording Changes

| Location | Previous | Updated |
| -------- | -------- | ------- |
| D-Day panel header | D-Day | 디데이 |
| D-Day add button | Add | 추가 |
| Memo panel header | Memo | 메모 |
| Memo new note | + New Note | + 새 노트 |
| Timeline header | Timeline | 타임라인 |
| Carry-over badge | continues … tomorrow | 내일 …까지 이어짐 |
| D-Day modal placeholder | e.g. Exam Day | 예: 시험일 |
| WeeklyTimetableSection days | Mon–Sun | 월–일 |
| Weekly add button | Add | 추가 |
| Weekly modal title | Edit Activity / New Activity | 활동 수정 / 새 활동 |
| Weekly time labels | Start / End | 시작 / 종료 |
| Weekly validation toast | End time must be later! | 종료 시간은 시작 시간보다 늦어야 합니다. |
| Weekly delete confirm | Delete this activity? | 이 활동을 삭제할까요? |
| Weekly save button | Save | 저장 |

*(Schedule / D-Day / routine modals already use `t()` for most fields.)*
