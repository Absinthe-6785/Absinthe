# K-30.43 — Source Note Audit

**Branch:** `k30-research-workflows`  
**Scope:** Task A — note classifications (Source / Literature / Permanent)

---

## Implemented

| Item | Description |
| ---- | ----------- |
| Property key | `noteKind` on note frontmatter (no schema change) |
| Values | `source`, `literature`, `permanent` |
| UI | `NoteClassificationSelector` in note header |
| Helpers | `getNoteKind`, `setNoteKind`, `filterNotesByKind` |

Users can mark a note as raw source material, processed literature, or permanent knowledge without altering the database layer.
