# K-30.34 — Archive Home Polish Audit

**Context:** Archive Home (`ArchiveHomeView`) presents Mark Calendar, Recent Transitions (milestones), Concerns (area pills), and Browse. Sections often display information without meaningful follow-through. **Audit only — no redesign in K-30.34.**

**Branch:** `k30-product-polish`

**Sources:** `ArchiveHomeView.tsx`, `ArchiveMarkCalendar.tsx`, `ArchiveRecentMilestones.tsx`, `ArchiveAreaPills.tsx`, `ArchiveBrowseLinks.tsx`, K-30.33 cross-tab notes.

---

## Current Layout

```
ArchiveHomeView
├── Header (frame title + subtitle)
├── Mark Calendar          ← heatmap grid, optional day/month click handlers
├── Recent Transitions     ← milestone list, wired → openNote()
├── Concerns (Area pills)  ← wired → openNote(area)
├── Browse                 ← links list, onBrowseClick optional (unused)
└── Empty message          ← when projection.empty
```

**Improvement since K-30.33:** Milestone and area pill clicks call `openNote()` (cross-tab navigation).

---

## 1. Empty States

| Section | Empty signal | Current copy / UX | Gap |
| ------- | ------------ | ----------------- | --- |
| **Global** | `projection.empty.isEmpty` | Muted paragraph at bottom | Competes with partially-filled sections; user may see both data and “empty” |
| **Mark Calendar** | `data-archive-mark-calendar-empty="true"` | Grid still renders; cells neutral | No explainer (“Mark days in Notes to see density”) |
| **Recent Transitions** | Zero milestones | Section may collapse or show quiet empty | Discoverability of how to create milestones unclear on Home |
| **Concerns** | No area notes | Pills hidden or sparse | No CTA to create first Area note |
| **Browse** | `links.length === 0` | `No archive destinations available.` | Correct but dead-end — no path to enable destinations |

**Priority:** Add purposeful empty CTAs (link to Notes trace/mark docs) before visual polish.

---

## 2. Dead-End Interactions

| Interaction | Wired? | Result today |
| ----------- | ------ | ------------ |
| Milestone row click | Yes (`openNote`) | Opens note in Notes tab |
| Area pill click | Yes (`openNote`) | Opens area note |
| **Mark Calendar day click** | **No** (`onDayClick` not passed) | Hover/tooltip only — no navigation |
| **Mark Calendar month click** | **No** | No drill-down |
| **Browse link click** | **No** (`onBrowseClick` omitted in Home) | Button renders but noop |
| Header subtitle | Display only | — |

**Highest-impact fix (future):** Wire Mark Calendar day → daily trace lens or filtered note list; wire Browse → timeline/period views per `archiveBrowsePresentation`.

---

## 3. Browse Usability

- **Projection-driven links** — `listArchiveBrowseLinkItems(browse)` builds destinations from archive index.
- **Labels** are readable (`data-archive-browse-label`) but **clicks go nowhere** on Home.
- **Empty browse** message does not explain prerequisites (marks, milestones, indexed periods).
- **No visual hierarchy** between primary vs secondary destinations — flat list.

**Recommendations:**
1. Pass `onBrowseClick` from `ArchiveHomeView` → switch Analytics sub-view or Notes trace range.
2. Group links: Time · Areas · Collections.
3. Show count badges (notes, marks) per destination when projection supports it.

---

## 4. Mark Calendar Opportunities

| Opportunity | Description | Effort |
| ----------- | ----------- | ------ |
| Day click → trace | Open `DailyTraceDayView` or Notes tab with `traceDate` | M |
| Month click → range lens | Quarter/month archive slice | M |
| Legend | Explain density colors vs exception marks | S |
| “You are here” | Stronger today indicator (already has `endDate`) | S |
| Empty onboarding | “Mark important days in Notes” with link | S |

Heatmap is the strongest visual on Home but the **least interactive** — largest polish ROI.

---

## 5. Milestone Discoverability

- **Recent Transitions** shows latest milestone notes but not how they are created (Event/Milestone dialogs in Notes).
- No link from empty milestone state to template or docs.
- Titles may be Japanese/Korean/English — good for content, but section header is English-only (see language audit).

**Recommendations:**
1. “Create milestone” secondary action → Notes with milestone template.
2. Show relative time + area tag on each row.
3. Cap list with “View all in timeline” when Browse wired.

---

## 6. Information Density

| Section | Density | Issue |
| ------- | ------- | ----- |
| Mark Calendar | High visual, low semantic | Many cells, tooltips only on hover |
| Milestones | Medium | Good when populated |
| Concerns | Low–medium | Pills wrap; no description preview |
| Browse | Low | List without metadata |

**Risk:** On wide screens, vertical stack feels like a dashboard without actions — user scrolls past non-interactive heatmap.

**Recommendations:** Collapse Mark Calendar when empty; expand milestone row to 2-line preview; add concern severity or mark count on pills.

---

## 7. Drill-Down Opportunities

```
Mark Calendar day
  → Daily trace (Notes tab) OR Archive day detail panel

Browse “2024 Q1”
  → Range trace lens (existing RangeTraceLensView)

Area pill
  → Area trace (already have AreaTraceView in Notes)

Milestone
  → Note (done) + back-link to Archive context
```

Unified **Archive → Notes trace** navigation API (extend `openNote` with trace params) would unlock most drill-downs without rewriting Home layout.
