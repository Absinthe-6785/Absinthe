# K-30.49 — Backspace Deletion Audit

**Branch:** `k30-editor-workspace-stabilization`  
**Scope:** Task A — backspace block deletion fix

---

## Root Cause

`shouldDeleteSelectedBlocks` returned `true` for any gutter-selected block with collapsed caret in a contentEditable, even when the block had text. The capture-phase handler in `useEditorKeyboard` deleted the block before `EditableBlock` could merge or delete characters.

---

## Fix

`blockKeyboard.ts` now requires:

- Non-empty CE blocks → never delete via capture handler
- Empty CE blocks → delete only when caret at offset 0 (Backspace) or Delete on empty shell
- Multi-select and non-CE shells unchanged

---

## Blocks Audited

| Block | Behavior |
| ----- | -------- |
| paragraph / heading | Text merge at offset 0 via EditableBlock |
| toggle | Toggle nesting guards in merge path |
| callout | Same as paragraph (CE) |
| question / answer | Shell blocks — block delete on shell focus |
| citation / footnote | CE or inline — text path preserved |
