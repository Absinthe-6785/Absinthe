# K-30.37 — Note Title Consistency Audit

**Branch:** `k30-workspace-consistency`  
**Scope:** Task C — unified untitled display strategy

---

## Decision

**Display placeholder:** `제목 없음` (Korean, aligned with K-30.36 sidebar area pills)

**Internal storage:** Unchanged — empty titles, legacy `'Untitled'` strings, and create paths that persist `'Untitled'` are preserved.

**Implementation:** `displayNoteTitle()` in `frontend/src/components/views/noteDisplayTitle.ts`

```ts
export const UNTITLED_NOTE_LABEL = '제목 없음';
// Maps empty, whitespace, and legacy 'Untitled' → 제목 없음
```
