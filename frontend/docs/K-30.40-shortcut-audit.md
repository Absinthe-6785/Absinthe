# K-30.40 — Keyboard Shortcut Help Audit

**Branch:** `k30-knowledge-authoring`  
**Scope:** Task D — shortcut discoverability overlay

---

## Implemented

| Surface | Trigger | Content |
| ------- | ------- | ------- |
| Block editor | `?` (outside inputs) | `ShortcutHelpOverlay` — formatting, headings, navigation, help |
| Block editor | `Ctrl+/` | Same overlay (editor root; avoids NoteView app modal) |
| Note shell | `Ctrl+/` (outside editor) | Existing NoteView shortcuts modal |
| Note shell | `?` (outside editor/inputs) | NoteView shortcuts modal |
