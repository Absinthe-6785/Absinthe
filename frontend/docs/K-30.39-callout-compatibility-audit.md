# K-30.39 — Callout Compatibility Audit

**Branch:** `k30-authoring-polish`  
**Scope:** Task C — Obsidian import aliases

---

## Supported Obsidian Syntax

| Obsidian alias | Absinthe preset | Icon |
| -------------- | --------------- | ---- |
| note, info | 정보 | ℹ |
| tip, hint | 팁 | 💡 |
| warning, caution, danger | 주의 | ⚠ |
| summary, abstract | 요약 | 📌 |
| question, faq, help | 질문 | ❓ |

**Parse patterns:**

- Single line: `> [!tip] Inline text`
- Multi-line body: continuation lines `> …` until next block

**Serialize:** Existing Absinthe format preserved — `> {icon} {content}` (emoji prefix). Obsidian syntax is import-only; export does not rewrite to `[!type]`.

**Implementation:** `calloutPresets.ts` (`OBSIDIAN_CALLOUT_ALIASES`), `blockUtils.ts` (`tryObsidianCallout`).

---

## Not Supported (future)

| Feature | Notes |
| ------- | ----- |
| Custom Obsidian admonition types (bug, example, failure, …) | Unmapped aliases fall through to quote/toggle parsers |
| Title + body split in Obsidian (`> [!note] Title` on line 1 only) | Stored as single content string |
| Foldable callouts | N/A |
| Round-trip Obsidian export | By design — Absinthe native format |

## Success Criteria

Obsidian `[!note]` / `[!tip]` / `[!warning]` / `[!summary]` / `[!question]` blocks import as Absinthe callouts with correct icons.
