# K-42 Area Evolution

Per-area note counts at recent period ends (up to 6 areas, 6 periods).

## Trend indicators

| Symbol | Meaning |
|--------|---------|
| ↑ | growing — last count > first |
| → | stable |
| ○ | dormant — flat and ≤2 notes |

## Grouping

Primary: `area` property → galaxy label → first tag.

Example display:

```
History ↑
January: 12 notes
February: 17 notes
March: 29 notes
```

No charts — list + trend symbol only.
