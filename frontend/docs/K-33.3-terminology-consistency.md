## Terminology Decision Log

1. **Cosmos > Universe** for all user-visible graph branding (K-33.3)
2. **Network** retained as technical counterpart to Cosmos mode (not "Classic graph")
3. **Galaxy** preferred in onboarding; **Area** retained as property key for backward compatibility
4. **Constellation** used in hints; **Learning path** remains panel title (familiar productivity term)
5. **Concept relations** use plain-language verbs (causes, depends on) not OWL jargon
