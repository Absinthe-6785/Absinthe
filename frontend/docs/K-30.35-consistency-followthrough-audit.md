# K-30.35 — Consistency Follow-through Audit

**Context:** K-30.35 shipped navigation wiring and language Phase 1. This document captures remaining friction after Planner Day default, Archive trace drill-down, and Notes search discoverability improvements.

**Branch:** `k30-navigation-consistency`

**Method:** Re-review of Planner, Archive, and Notes surfaces against K-30.34 audits and K-30.35 implementation scope.

---

## K-30.35 Shipped

| Task | Change |
| ---- | ------ |
| **A — Planner entry** | `DEFAULT_PLANNER_CALENDAR_MODE = 'day'` |

| **C — Browse wiring** | `openArchiveBrowseDestination()` → Notes trace range/discovery |

## 4. Recommended Priority Order

| Priority | Item | Rationale |
| -------- | ---- | ----------- |
| **P1** | Notes sidebar + shortcuts panel Korean pass | Highest daily visibility after Phase 1 |
| **P1** | Planner mobile default tab → calendar | Completes Day-first IA |
| **P2** | Slash menu + selection toolbar Korean | Edit flow consistency |
| **P2** | Archive frame title + projection label localization | Archive feels cohesive |
| **P2** | Shortcuts panel: document Ctrl+F search, Ctrl+Shift+F focus | Prevents regression confusion |
| **P3** | Browse “All areas” → area trace list or first area | Clearer than discovery |
| **P3** | Timeline demote/collapse on desktop | Reduces duplication |
| **P3** | H4 heading + TOC support | Editor hierarchy (K-30.34 backlog) |
| **P4** | Archive Shell period/timeline placeholders → real views | Larger milestone |
